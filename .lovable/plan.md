# سایت چادر دوزی — فروشگاهی + خدماتی

## هدف
ساخت یه سایت فارسی و راست‌چین برای کسب‌وکار چادر دوزی که هم محصولات رو بفروشه (چادر مسافرتی، برزنتی، کانتینری و ...) و هم خدمات دوخت، تعمیر و سفارشی‌سازی رو معرفی کنه.

## محدوده MVP (قابل تحویل در یک ماه)
- صفحه اصلی: هیرو، معرفی محصولات پرفروش، معرفی خدمات، CTA تماس
- فروشگاه: لیست محصولات با فیلتر دسته‌بندی
- جزئیات محصول: تصویر، توضیحات، قیمت، دکمه افزودن به سبد
- سبد خرید: افزودن/حذف/تغییر تعداد
- خدمات: توضیح خدمات دوخت، تعمیر، سفارشی
- درباره ما: داستان برند
- تماس: فرم + اطلاعات تماس
- فوتر و هدر مشترک با لینک به همه صفحات

## زبان و جهت
- زبان: فارسی
- جهت: راست‌چین (RTL)
- تایپوگرافی: فونت فارسی مناسب

## طراحی
- تم تیره/روشن متعادل با رنگ‌های صنعتی (آبی/نارنجی/خاکستری)
- کارت‌های محصول واضح
- تصاویر محصولات با placeholder تا کاربر تصاویر واقعی جایگزین کنه

## فنی
- TanStack Start + React + TypeScript
- Tailwind CSS v4
- مدیریت سبد خرید با React state (localStorage)
- فرم تماس سمت سرور
- متا تگ‌های سئو روی هر صفحه

1. راه‌اندازی ساختار پروژه و فونت فارسی

6. بررسی نهایی و بهینه‌سازی
